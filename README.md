# Toyota Hilux — 3D Studio

Интерактивная 3D-модель Toyota Hilux Double Cab в браузере: размеры, рулетка, проверка груза в кузове, тюнинг (кунг, багажник, люстра, спортбар, шноркель, силовой бампер, колёса 33″), заметки и режим показа.

Вкладка «Анимация»: езда по дороге с выбором скорости, открывание дверей, капота и заднего борта, фары и аварийка, окружение — студия с сеткой, дорога или мастерская.

Вкладка «Проекты PIRANT»: проект LED-панелей на кузов. На модели — багажник из профтрубы в кузове, по его краям две LED-панели 1490×690 мм, сверху динамики с «живым» видео 16:9 (P3.076/P4, день/ночь, раскладка модулей, своё видео). В панели — выводы по КП, смета с проверкой арифметики, требования и хронология. Эскиз — `sketch.png`.

Там же проект «Кунг связи» (по списку оборудования и схеме размещения): кунг с прозрачными или обычными стенками, 18 пронумерованных позиций (стойка 19″, телефоны, отопитель, катушка, ТВ, принтер, генератор, АКБ, инвертор, щит, Starlink mini, антенна AKS, мачты, фонари, багажник), кабельные трассы 220/12 В, подъём мачт, ночной режим, два варианта установки ТВ. В панели — список оборудования с переходом к позиции, выводы по компоновке, принципиальная схема электроснабжения 220 В / 12 В с исправлениями и баланс мощности. Переключатель «Схема питания в 3D» показывает линии схемы на модели (от бортовой АКБ под капотом до щита, ИБП и потребителей, шина PE и заземлитель), «Генератор снаружи» выносит генератор на катушку. Картинка проекта — `kung.jpg`, фото исходной схемы — `power-scheme.jpg`.

Сайт — один файл `index.html` (three.js r128), модель `pickup.glb` встроена в него.

## Обновить модель из Blender
1. Экспортируйте модель в `pickup.glb` (glTF Binary) в эту папку.
2. Запустите `node embed-model.js` — модель встроится в `index.html`.
